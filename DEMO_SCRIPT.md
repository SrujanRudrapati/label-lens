# 3-minute demo video script

Record on your phone screen (screen recording) + voiceover. Record in segments, stitch after.
Use the REAL API for the recording, not mock mode.

0:00–0:15  Hook. Hold a medicine box. "My grandmother takes 6 medications. Can she take this
           for her back pain? The answer is on this box, in 6-point type." Name + team.
0:15–0:25  "This is Label Lens." Open the app on the phone. Profile already set:
           warfarin, peanut allergy, language English.
0:25–1:05  Scan the ibuprofen box live. Point out: instant product name (Haiku), then the
           caution sticker appears. Tap it: shows the exact label text as evidence.
           Tap Read aloud (let ~5 s play).
1:05–1:35  Scan the snack. Red allergen sticker. Tap it: "may contain peanuts" quoted.
1:35–2:00  Switch language to Spanish, rescan or reload: full explanation in Spanish,
           evidence still in English. Ask a follow-up: "Is acetaminophen safer for me?"
           Show streamed answer that ends with "confirm with your pharmacist".
2:00–2:35  How the AI works (one simple diagram on screen): Haiku + Sonnet in parallel,
           structured output, evidence grounding = no invented warnings, profile stays on
           the device.
2:35–2:55  Impact: allergies, polypharmacy, language barriers, low vision. Free to run,
           works in any browser, no account.
2:55–3:00  Live URL + GitHub on screen. "Label Lens. Read the fine print for you."

Before uploading: watch it once at 1x, cut every pause, check audio, set YouTube to
Public/Unlisted, test the link in an incognito window.
